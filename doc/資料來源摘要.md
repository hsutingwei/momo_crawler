## 1️⃣ Dataset Summary（資料來源摘要）

### 資料來源
| 項目 | 詳情 |
|------|------|
| **電商平台** | Momo 購物網站 (momoshop.com.tw) |
| **資料類型** | 商品基本資訊 + 買家評論 + 銷售快照 |
| **爬蟲 API** | `https://eccapi.momoshop.com.tw/user/getGoodsCommentList` (POST) |
| **爬蟲工具** | Selenium Wire + Chrome WebDriver + Requests |

### 商品類別（關鍵字）
`口罩`、`益生菌`、`葉黃素`、`維他命`、`膠原蛋白`、`雞精`（共 6 個品類）

### 資料庫結構（PostgreSQL）
| 資料表 | 說明 |
|--------|------|
| `products` | 商品基本資料（ID, 名稱, 價格, 連結, keyword） |
| `sales_snapshots` | 銷售數量快照（按時間戳記錄，每次爬蟲寫一筆） |
| `product_comments` | 商品評論（含評論文字, 時間, 評分, 圖片, 按讚數） |
| `comment_tokens` | CKIP 斷詞結果（token, POS tag, 順序） |
| `comment_semantic_scores` | BERT 語意分數（Arousal, Novelty, Repurchase, Negative, Advertisement） |
| `tfidf_vocab / tfidf_term_freq / tfidf_doc_freq` | TF-IDF 詞典索引 |
| `ml_data_filters` | 欲排除商品的過濾清單（可於實驗中啟用） |

### 爬蟲設計細節
- 每次爬蟲以 `資料擷取時間 (capture_time)` 為標記，形成時間序列快照
- 支援指定截止時間（`--designate_capture_time`），只抓指定時間點之前的評論
- 評論去重機制：以 `留言ID (commentId)` 為主鍵避免重複爬取
- 防反爬：隨機暫停 0.5~1.2 秒，simulate 真實使用者行為

### Cutoff Time
- **訓練截止日**（Date Cutoff）: `2025-06-25`
- 截止日之前的評論作為特徵輸入，截止日之後的銷售變化作為標籤

### Label 定義（二元分類）

#### 標籤模式（Label Strategy）
程式支援 `absolute`（預設）與 `hybrid` 兩種：

| 策略 | 定義 | SQL 邏輯 |
|------|------|----------|
| **absolute** | 截止日後，下一批快照銷售量 Δ ≥ [delta_threshold](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/Model/data_loader.py#74-103)（預設 10） | [(sales_count - prev_sales) >= delta_threshold](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335) |
| **hybrid** | 同時需滿足絕對 Δ ≥ threshold **且** 相對成長率 ≥ `ratio_threshold`（預設 1.0 = 100%） | 同上 + [((sales_count / prev_sales) - 1) >= ratio_threshold](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335) |

#### 銷售級距（Sales Buckets）
銷售量按以下離散區間分桶，label 定義基於「跨越幾個 bucket」：
```
[0, 1, 5, 10, 20, 30, 50, 100, 500, 1000, 3000, 5000, 8000, 10000, 30000, 50000, ...]
```

#### 標籤模式（Label Mode）
| 模式 | 說明 |
|------|------|
| `next_batch` | 比較截止日前後兩個最近批次的銷售量 |
| `fixed_window` | 在截止日後固定的時間窗口（`label_window_days=7`天）內，看銷售量是否達標 |

#### 正類定義（爆品 = Positive Label）
- `y = 1`：商品在截止日後的快照中銷售量顯著增加（滿足 delta + 可選 ratio 條件）
- `y = 0`：銷售量未顯著增加（非爆品）

> 最終訓練時選用 label strategy（`absolute`），以及確切的 [delta_threshold] 10.0

## 2️⃣ Preprocessing Pipeline（資料前處理流程）

### 文本處理步驟（preprocess_v2.py）

```
原始評論 CSV
  ↓ 1. 換行字元修復 (repair_broken_csv)
  ↓ 2. Unicode 正規化 (NFKC) — 全形→半形
  ↓ 3. 簡→繁轉換 (OpenCC: s2tw)
  ↓ 4. 移除 URL、控制字元、規整空白
  ↓ 5. 保留漢字，非中文替換為分隔符 ';' (sanitize_chinese)
  ↓ 6. CKIP BERT 斷詞 + POS 詞性標注 (CkipWordSegmenter, bert-base, GPU)
  ↓ 7. 長詞後向最大匹配切分 (RMM, 3字→2字→單字)
  ↓ 輸出: norm_text (CSV) + tokens/POS (JSONL)
```

### 斷詞過濾策略（seg.py + preprocess_v2.py）
- **保留詞性**：名詞 (`N*`) + 動詞 (`V*`)（CKIP POS tag）
- **去除單字詞**：`len(token) > 1` 才保留
- **不使用傳統停用詞表**：改以詞性標注自動過濾助詞、語氣詞等

### 文本特徵方法

| 方法 | 實作 | 用途 |
|------|------|------|
| **TF-IDF** | sklearn `TfidfVectorizer` (top 200 詞, max_features) | 主文本特徵（K-Fold 內 pre-fit on train_pool） |
| **SBERT Sentence Embedding** | `all-MiniLM-L6-v2` | 語意熵 (feat_entropy_emb) 計算 |
| **BERT Zero-Shot Classification** | `comment_semantic_scores` 表 | Arousal / Novelty / Repurchase / Negative / Advertisement |
| **Category TF-IDF** | 2000 維，計算品類中心點餘弦相似度 | category_fit_score |

## 3️⃣ Feature Table（特徵總表）

### A. 物理運動學特徵（Kinematics / Physical）

| Feature Name | Description | Formula / Source |
|---|---|---|
| `kin_v_1` | 當週評論速度（最近7天） | `COUNT(comment_date in [cutoff-7d, cutoff])` |
| `kin_v_2` | 上週評論速度（7~14天前） | `COUNT(comment_date in [cutoff-14d, cutoff-7d))` |
| `kin_v_3` | 基準評論速度（14~21天前） | `COUNT(comment_date in [cutoff-21d, cutoff-14d))` |
| `kin_acc_abs` | 絕對加速度 | `kin_v_1 - kin_v_2` |
| `kin_acc_rel` | 相對加速度（對數尺度） | [(log1p(v1) - log1p(v2)) / (log1p(v2) + 1)](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335) |
| `kin_jerk_abs` | 衝擊度（加速度的變化率） | `kin_v_1 - 2*kin_v_2 + kin_v_3` |
| `comment_count_pre` | 截止日前累積總評論數 | `COUNT(comment)` |
| `comment_count_7d` | 近7天評論數 | 同 kin_v_1 |
| `comment_count_30d` | 近30天評論數 | COUNT |
| `comment_count_90d` | 近90天評論數 | COUNT |
| `comment_3rd_30d` | 最近30天評論（第三區間） | TIME FILTER |
| `comment_2nd_30d` | 31~60天評論（第二區間） | TIME FILTER |
| `comment_1st_30d` | 61~90天評論（第一區間） | TIME FILTER |
| `days_since_last_comment` | 距最後評論天數（新近性） | [(cutoff - MAX(comment_date)) / 86400](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335) |
| `price` | 商品價格 | JOIN products |
| `score_mean` | 評論平均星數（整體） | `AVG(score)` |
| `sentiment_mean_recent` | 近90天平均評分 | `AVG(score) FILTER 90d` |
| `pos_count_recent` | 近90天正評數（≥4星） | COUNT |
| `neg_count_recent` | 近90天負評數（≤2星） | COUNT |
| `promo_count_recent` | 近90天促銷相關評論數 | REGEX match |
| `like_count_sum` | 評論按讚總數 | `SUM(like_count)` |
| `has_image_urls` | 是否有圖片評論 | MAX |
| `image_urls_count` | 圖片評論總張數 | SUM |
| `has_video_url` | 是否有影片評論 | MAX |
| `has_reply_content` | 是否有商家回覆 | MAX |

### B. 語意特徵（Semantic / BERT Zero-Shot）

| Feature Name | Description | Source |
|---|---|---|
| `bert_arousal_mean` | 近90天評論「興奮/激動」情緒平均機率 | `comment_semantic_scores.score_arousal` |
| `bert_novelty_mean` | 近90天評論「新奇感」平均機率 | `score_novelty` |
| `bert_repurchase_mean` | 近90天「回購意願」平均機率 | `score_repurchase` |
| `bert_negative_mean` | 近90天「負面情緒」平均機率 | `score_negative` |
| `bert_advertisement_mean` | 近90天「廣告/業配」平均機率 | `score_advertisement` |
| `category_fit_score` | 品類適配度（商品評論與品類中心點的餘弦相似度） | TF-IDF(2000維) + cosine similarity |

### C. 心理 / 資訊理論特徵（Psychological / Information-Theoretic）

| Feature Name | Description | Method |
|---|---|---|
| `feat_entropy_tfidf` | 語意熵（TF-IDF版，K-Means 5群 Shannon Entropy） | KMeans(5) + scipy.stats.entropy |
| `feat_entropy_emb` | 語意熵（SBERT版，語意嵌入聚類） | SBERT + KMeans(5) + entropy |
| `feat_temporal_burstiness` | 時間突發性（評論間隔時間的 Burstiness 指標） | [(r-1)/(r+1)](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335), r=std/mean of IAT |
| `feat_lexical_diversity` | 詞彙多樣性（Guiraud's R） | [(100 * log(N)) / (1 - V1/V)](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335) |
| `feat_compression_ratio` | 壓縮比（zlib，高比值=高資訊密度=真實） | `len(original) / len(compressed)` |
| `feat_ncd_spam` | 標準化壓縮距離（與9個範本刷評的相似度） | NCD formula with SPAM_REFERENCES |

### D. 融合 / 交互特徵（Fusion / Interaction）

| Feature Name | Description | Formula |
|---|---|---|
| `quality_driven_momentum` | 品質驅動動量 | `kin_acc_abs * category_fit_score` |
| `early_bird_momentum` | 早鳥動量 | `kin_acc_abs * (1 / (log1p(comment_count_90d)+1))` |
| `momentum_tfidf` | 動量（TF-IDF版） | `kin_acc_abs * (category_fit_score+0.5) * (feat_entropy_tfidf+0.5)` |
| `momentum_emb` / `authentic_momentum` | 真實動量（SBERT版） | `kin_acc_abs * (category_fit_score+0.5) * (feat_entropy_emb+0.5)` |
| `validated_velocity` | 驗證速度（音量加權） | `ratio_recent30_to_prev60 * log1p(comment_3rd_30d)` |
| `novelty_momentum` | 新奇動量 | `ratio_recent30_to_prev60 * (1 - repurchase_ratio_recent)` |
| `price_weighted_arousal` | 價格加權情緒 | `bert_arousal_mean * log1p(price)` |
| `price_weighted_novelty` | 價格加權新奇 | `bert_novelty_mean * log1p(price)` |
| `is_mature_product` | 是否為成熟商品（二元旗標） | [(comment_count_pre > 50) OR (repurchase_ratio > 0.2)](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/build_tfidf_index.py#259-335) |
| `spam_risk_score` | 垃圾刷評風險分數 | 觸發條件: count_90d>5 AND entropy<0.5 → 值=kin_acc_abs |

### E. TF-IDF 文本特徵（Text Feature Matrix）

| 項目 | 詳情 |
|------|------|
| **維度** | Top-200 tokens（`--tfidf-dim 200`，可調整） |
| **Fit 範圍** | 僅在 train_pool（80%）上 fit，test set 不參與 |
| **Tokenizer** | 若文本已斷詞（有空格）→ `str.split`；否則 → `char_wb ngram(2~4)` |
| **Lowercase** | False（保留原始大小寫/中文字元） |
| **來源** | `doc_text_tokenized`（來自 `comment_tokens` CKIP 斷詞結果） |

## 5️⃣ Dimensionality Reduction（降維）

根據程式碼分析：
- **無顯式 DR 方法**（PCA / SVD / t-SNE 等）
- TF-IDF 透過 `max_features=200` 限制向量維度（屬於 Top-K 截斷，而非 PCA）
- 語意熵計算中使用 `KMeans(n_clusters=5)` 作為文字的主題聚類（非降維目的，屬特徵工程）
- Category Fit Score 中 TF-IDF 使用 2000 維，但只輸出一個標量特徵

## 6️⃣ Experiment Pipeline（實驗流程）

### Pipeline 設計（train_v2.py 7-Phase ML Pipeline）

```
Data (PostgreSQL DB)
│
├─ load_product_level_training_set() [data_loader.py]
│   ├─ SQL: 計算所有 Dense 特徵（SQL aggregation）
│   ├─ SQL: 計算 Label y（next_batch / fixed_window）
│   └─ Python: SBERT/TF-IDF/Compression 特徵計算
│
├─ Phase 1: 初始化 Run（run_id, output dir, Git info）
├─ Phase 2: 資料切分
│   ├─ Stratified 8:2 Holdout Split（固定 random_seed=42）
│   └─ Stratified K-Fold CV on train_pool（預設 10 folds）
├─ Phase 3: TF-IDF Prefit（僅在 train_pool 上 fit，test 只 transform）
├─ Phase 4: K-Fold 訓練迴圈
│   ├─ Dense features → FeatureTransformer（fit only on train_fold）
│   ├─ TF-IDF → slice from prefit matrix（無洩漏）
│   ├─ Merge: hstack([dense_transformed, tfidf_sliced])
│   ├─ Data Leakage Check（5項自動化洩漏檢查）
│   └─ 訓練 → 預測 OOF → 計算 AUC, F1, Precision, Recall
├─ Phase 5: 最終模型訓練（用完整 train_pool，同 prefit TF-IDF）
├─ Phase 6: Threshold 調整（fixed=0.5 / tuned=OOF F1 / locked）
└─ Phase 7: 儲存 Artifacts + 資料庫記錄
```

### 消融研究（Ablation Study）支援
- 使用 `--force-use-splits` 強制使用相同切分（保證對照實驗公平性）
- 使用 `--hyperparameter-mode locked` 鎖定超參數（消除超參誤差）
- 使用 `--threshold-mode locked` 鎖定閾值
- `split_hash / dataset_hash / feature_hash` 紀錄可復現性

## 7️⃣ Classification Model（分類模型）

### 支援的模型

| 模型 | 實作 | 超參數（預設） |
|------|------|---------------|
| **XGBoost**（主要） | `xgb.XGBClassifier` | `max_depth=6, learning_rate=0.1, n_estimators=100, tree_method=gpu_hist` |
| **LightGBM** | `lgb.LGBMClassifier` | `max_depth=6, learning_rate=0.1, n_estimators=100, device=gpu` |
| **Logistic Regression** | `sklearn.LogisticRegression` | `max_iter=1000, solver=default` |
| **Linear SVM** | `sklearn.SVC` | `kernel=linear, probability=True, cache_size=4000MB` |

### 類別不平衡處理
- **方法**：`scale_pos_weight`（自動計算 neg/pos 比例）
- **計算範圍**：`fold_train`（每個 fold 的訓練集各自計算），可選 `train_pool`
- XGBoost/LightGBM 直接傳入 `scale_pos_weight` 參數
- LR/SVM 使用 `class_weight={0: 1.0, 1: spw}` 等效實作

### 硬體加速
- GPU 加速（`tree_method=gpu_hist`）
- 32 CPU 核心並行（`n_jobs=32`）

### 訓練策略
- **先做 K-Fold CV**（得 OOF 預測），再對完整 train_pool 訓練最終模型
- 對 test set 的最終評估完全基於最終模型預測
- 隨機種子固定（`random_seed=42`）保證可復現性

## 8️⃣ Evaluation Metrics（評估指標）

### 分類任務類型
- **二元分類（Binary Classification）**：爆品（1）vs 非爆品（0）

### 評估指標

| 指標 | 說明 | 程式實作 |
|------|------|---------|
| **ROC-AUC** | 主要比較指標；不受閾值影響 | `sklearn.metrics.roc_auc_score` |
| **F1-Score** | 精確率與召回率的調和均值（應對不平衡） | `sklearn.metrics.f1_score` |
| **Precision** | 精確率 | `sklearn.metrics.precision_score` |
| **Recall** | 召回率 | `sklearn.metrics.recall_score` |

### 評估策略

| 評估集 | 說明 | 輸出 |
|--------|------|------|
| **OOF（Out-of-Fold）Aggregate** | 每個 fold 的均值 ± 標準差 | `AUC_mean ± AUC_std, F1_mean ± F1_std` |
| **OOF Global** | 拼接所有 fold 的 OOF 預測計算 | 單一 AUC, F1, Precision, Recall |
| **Test Set** | 最終模型對 holdout 20% 的預測 | AUC, F1, Precision, Recall |

### 分類閾值（Decision Threshold）
| 模式 | 說明 |
|------|------|
| `fixed` | 固定 0.5 |
| `tuned` | 在 OOF 預測上搜尋最佳 F1（步長 0.01） |
| `locked` | 使用 baseline 實驗的最佳閾值（消融研究用） |

## 9️⃣ Data Split（資料切分）

### 切分策略

```
全部資料（N 個商品）
     ↓ Stratified 8:2 Split（random_seed=42）
┌──────────────────────────────────┐
│ Train Pool (80%)                 │
│  ↓ Stratified 10-Fold CV        │
│  ┌ Fold 0: train 9/10 + val 1/10│
│  ├ Fold 1: train 9/10 + val 1/10│
│  ├ ...                           │
│  └ Fold 9: train 9/10 + val 1/10│
└──────────────────────────────────┘
┌──────────────────────────────────┐
│ Test Set (20%)                   │
│  → 僅用於最終評估，從不參與訓練  │
└──────────────────────────────────┘
```

| 參數 | 值 |
|------|---|
| **Train/Test Split** | 80% / 20% |
| **K-Fold** | Stratified K-Fold, K=10 |
| **Random Seed** | 42（固定，保證可復現） |
| **Holdout Strategy** | Stratified（保持正負類比例） |
| **分析單位** | Product Level（每筆 = 一個商品） |

### 資料洩漏防止（Data Leakage Prevention）
- TF-IDF Vectorizer 僅 fit 在 `train_pool`（80%），test set 只 transform
- Dense 特徵的 FeatureTransformer 僅 fit 在 `train_fold`（每個 fold 的訓練部份）
- 5 項自動化洩漏檢查（[leakage_prevention.py](file:///c:/YvesProject/%E4%B8%AD%E5%A4%AE/%E7%B7%9A%E4%B8%8A%E8%A9%95%E8%AB%96/momo_crawler-main/Model/leakage_prevention.py)）於每個 fold 執行
- 截止日設計保證：特徵（cutoff 前評論）與標籤（cutoff 後銷售）嚴格分離

## 10️⃣ Full Research Workflow（完整研究流程）

```
1. 資料收集層（Data Collection）
   crawler.py + crawler_pipline.bat
   → Selenium 爬蟲：搜尋結果頁 + API 抓評論 + 銷售快照
   → 輸出: {keyword}_商品資料.csv, crawler/{keyword}_商品留言資料*.csv

2. 資料入庫層（Data Ingestion）
   csv_to_db.py
   → 資料驗證 + 去重 + 批量寫入 PostgreSQL
   → 資料表: products, sales_snapshots, product_comments

3. 文本前處理層（Text Preprocessing）
   preprocess_v2.py
   → 換行修復 → Unicode/繁簡正規化 → 去除 URL/控制字元
   → CKIP BERT 斷詞 + POS 標注（GPU 加速）
   → 輸出 JSONL: {msg_id, norm_text, tokens, pos}

4. TF-IDF 索引建立層（TF-IDF Indexing）
   upload_preprocessed_to_db.py → comment_tokens 表
   build_tfidf_index.py
   → 計算全語料 TF/DF → 寫入 tfidf_vocab / tfidf_term_freq / tfidf_doc_freq

5. 特徵工程層（Feature Engineering）
   data_loader.py (load_product_level_training_set)
   → SQL: 計算運動學特徵（kin_v1/v2/v3, acc, jerk）
   → SQL: 計算 BERT 語意特徵（arousal 等 5 個維度）
   → Python: 計算資訊理論特徵（entropy, burstiness, diversity, compression, NCD）
   → Python: 計算融合特徵（authentic_momentum, spam_risk_score 等）
   → SQL: 計算標籤 y（next_batch 或 fixed_window 策略）

6. 模型訓練與評估層（Model Training & Evaluation）
   train_v2.py
   → Stratified 8:2 holdout split + 10-Fold Stratified CV
   → TF-IDF prefit（train_pool only）
   → K-Fold 迴圈訓練（XGBoost / LightGBM / LR / SVM）
   → 不平衡處理（scale_pos_weight）
   → 洩漏檢查（5 項自動化）
   → OOF 評估 + 最終模型訓練 + Test 評估

7. 結果記錄層（Result Logging）
   → 輸出 artifacts: splits.parquet, metrics.json, predictions_oof.parquet 等 15+ 個文件
   → 寫入 PostgreSQL 實驗追蹤表（ml_runs 等）
   → 支援消融研究重現
```
