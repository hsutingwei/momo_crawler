# 語意特徵 Verbalizer 之語料導向擴充方法（Corpus-Guided Verbalizer Refinement）

## 3.x 方法定位

本研究所定義之語意特徵（Semantic Features, SF）涵蓋五個語意維度：情緒喚醒度（High_Arousal）、新奇感（High_Novelty）、再購意願（High_Repurchase_Intent）、負面抱怨（Negative_Complaint）與疑似業配（Advertisement）。各維度的理論定義維持固定，如下所示：

- **bert_arousal_mean**：識別評論中具有高情緒喚醒度與驚豔色彩的情感表述。
- **bert_novelty_mean**：反映消費者對產品性能或使用體驗超出預期的新奇感受。
- **bert_repurchase_intent_mean**：表徵消費者對品牌或特定商品的再次購買意願與忠誠度。
- **bert_negative_mean**：量化評論中負面抱怨、失望情緒或反向推薦的強度。
- **bert_advertisement_mean**：捕捉評論語氣中可能存在的模板化、過度修飾或疑似業配操作等異常訊號。

在零樣本（zero-shot）自然語言推論（Natural Language Inference, NLI）框架中，上述各語意維度必須透過文字化描述（verbalizer）傳遞給預訓練語言模型，作為假設（hypothesis）端的語意錨點。初始 verbalizer（即 seed label descriptions）以簡短短語概括各維度的核心語意，例如：

```
High_Arousal:           "驚豔、激動、太神了"
High_Novelty:           "新奇、初次體驗、相見恨晚"
High_Repurchase_Intent: "回購意願高、忠實粉絲"
Negative_Complaint:     "憤怒、失望、反推"
Advertisement:          "業配、廣告、湊字數"
```

然而，在中文電商評論這種高度口語化、品類混雜、語言風格多變的語境中，單一短語作為語意描述往往存在覆蓋不足的問題。評論者可能以「囤一波」表達再購意願，以「傻眼」表達負面情緒，以「代言人」暗示業配屬性；這些表達方式在語義上明確，但與 seed label descriptions 的字面形式相距甚遠，導致 NLI 模型在推論時的信號強度不穩定甚至遺漏。

有鑑於此，本研究進一步設計一套**語料導向的 verbalizer 擴充流程（corpus-guided verbalizer refinement）**，其核心思路為：在不改變各語意維度之理論定義的前提下，從本研究實際爬取的中文電商評論語料中挖掘與各維度相符的高頻表達用詞，作為 verbalizer 的補充描述。整體流程分為四個階段：高信心評論篩選、候選詞挖掘、人工審閱、verbalizer 擴充，以下各節依序說明。

---

## 3.x+1 整體流程概覽

本研究所設計之 verbalizer 擴充流程如下圖所示，分為兩個自動化計算步驟（sf_01, sf_02）與一個人工審閱環節：

```
comment_semantic_scores（seed NLI 初始分數）
        │
        ▼ [sf_01_filter_highconf.py]
sf_highconf_comments（各 label 高信心評論子集）
        │
        ▼ [sf_02_mine_candidates.py]
sf_keyword_candidates（候選詞列表，附 discriminative score、詞性、例句）
        │
        ▼ [人工審閱]
擴充版 label_map（verbalizer）
```

整體設計兼顧語料適應性與人工可解釋性：自動化步驟負責從大量語料中高效率地挑選語意相關的候選詞，人工審閱環節則確保最終納入的關鍵詞確實符合各維度的理論語意，而非單純的統計巧合。

## 3.x+2 步驟一：高信心評論篩選

### 3.x+2.1 設計動機

verbalizer 擴充的第一個挑戰在於資料來源的雜訊問題。若直接對全體評論進行詞彙挖掘，高頻詞彙往往以通用性詞彙（如「商品」、「不錯」、「感覺」）為主，難以有效反映各語意維度的特殊表達模式。為此，本研究先以已計算完成的 seed NLI 分數（即 `comment_semantic_scores` 資料表），篩選出在各語意維度上具有高置信度（high confidence）的評論子集，以此作為後續詞彙挖掘的語料基礎。

### 3.x+2.2 篩選邏輯

本步驟之實作對應程式 `sf_01_filter_highconf.py`。對每個語意 label，從 `comment_semantic_scores` 資料表中擷取對應欄位的 NLI 分數，並套用以下兩層篩選條件：

**（一）主要分數門檻（threshold）**  
要求目標語意維度的 NLI 分數不低於預設門檻值，以確保候選評論在該維度上確實具有顯著信號。本研究各維度的預設門檻設定如下：

| label | 對應欄位 | 預設門檻 |
|---|---|---|
| High_Arousal | score_arousal | 0.70 |
| High_Novelty | score_novelty | 0.70 |
| High_Repurchase_Intent | score_repurchase | 0.70 |
| Negative_Complaint | score_negative | 0.65 |
| Advertisement | score_advertisement | 0.65 |

情緒性語意（Arousal、Novelty）的門檻相對較高（0.70），以確保篩選出的評論在語意上確實具有強烈的喚醒度或新奇感；負面情緒與業配語意（0.65）則略低，反映這兩類語意在中文口語中表達形式較為多樣，過高門檻會導致樣本不足。

**（二）排除條件（exclusion constraints）**  
為降低混合語意污染（mixed-signal contamination），避免篩選出的評論同時帶有多個語意維度的強烈信號，本研究對部分 label 加入排除條件：若評論在某些其他語意維度的分數超過特定上限，則不納入本輪高信心集合。

以 High_Arousal 為例，其篩選條件要求：

```
score_arousal >= 0.70
  AND score_advertisement < 0.40   -- 排除疑似業配的高喚醒評論
  AND score_negative      < 0.35   -- 排除負面情緒中的高喚醒
```

此設計確保高信心子語料的語意純度，使後續挖掘出的候選詞更具各維度的語意代表性，而非語料中跨維度共現的噪聲詞彙。

### 3.x+2.3 輸出

通過上述兩層篩選的評論，連同其所屬 label、本輪篩選 run_id 及對應 NLI 分數，批次寫入 `sf_highconf_comments` 資料表，作為步驟二的語料輸入。系統設計支援乾跑模式（dry-run），供研究者在正式寫入前確認各 label 的篩選數量與分數分布，若樣本數低於 100 筆，程式將發出警告，建議降低門檻或檢查資料來源。

## 3.x+3 步驟二：候選詞挖掘

### 3.x+3.1 設計動機

在確立各語意維度的高信心評論子集後，下一步是從中挖掘具有語意鑑別力的詞彙作為 verbalizer 候選詞。此步驟之核心問題在於：如何在語料中找到「對特定語意維度具有區分能力，而非全語料普遍高頻」的詞彙。

純粹以人工方式擴充 verbalizer 有兩個限制：第一，人工列舉難以窮盡中文口語表達的多樣性；第二，缺乏語料頻率依據，難以判斷候選詞是否確實在相關評論中穩定出現。因此，本研究採用半自動方式：透過量化的差異化分數（discriminative score）從語料中挖掘候選詞，再經由人工審閱確認語意合理性，兼顧語料適應性與可解釋性。

此步驟之實作對應程式 `sf_02_mine_candidates.py`。

### 3.x+3.2 資料來源

本步驟結合以下四個資料來源進行計算：

- **`sf_highconf_comments`**：步驟一輸出的高信心評論 ID 集合，界定 label 子語料的範圍。
- **`tfidf_term_freq`**：全語料的 term-document 詞頻矩陣（TF），用於計算 label 子語料的詞彙頻率統計。
- **`tfidf_doc_freq`**：全語料各詞彙的文件頻率（DF），作為 discriminative score 的分母基準。
- **`tfidf_vocab`**：詞彙表，記錄 term_id 與對應的詞彙字串及 pipeline 版本。
- **`tfidf_corpus`**：記錄全語料總文件數（total_docs），用於分母的歸一化計算。

## 3.x+4 Discriminative Score 公式

### 3.x+4.1 公式定義

對於語意維度 $l$ 的高信心評論子集 $\mathcal{D}_l$，以及全語料 $\mathcal{D}$，本研究定義詞彙 $w$ 的差異化分數（discriminative score）如下：

$$
\text{disc\_score}(w, l) = \ln\!\left(\frac{\,\text{TF}_l(w) \;/\; |\mathcal{D}_l|\,}{\;\text{DF}(w) \;/\; |\mathcal{D}| + \varepsilon\;}\right)
$$

其中各變數定義如下：

| 符號 | 定義 |
|---|---|
| $\text{TF}_l(w)$ | 詞彙 $w$ 在 label $l$ 之高信心評論子集 $\mathcal{D}_l$ 中的總詞頻（所有文件的詞頻加總） |
| $\vert\mathcal{D}_l\vert$ | label $l$ 之高信心評論子集的文件總數 |
| $\text{DF}(w)$ | 詞彙 $w$ 在全語料 $\mathcal{D}$ 中的文件頻率（出現在多少篇文件中） |
| $\vert\mathcal{D}\vert$ | 全語料的總文件數 |
| $\varepsilon$ | 平滑項（smoothing constant），本研究設定為 $0.001$ |

### 3.x+4.2 直觀解釋

分子 $\text{TF}_l(w) / |\mathcal{D}_l|$ 代表詞彙 $w$ 在 label 子語料中的平均每文件詞頻，反映該詞在語意相關評論中出現的密集程度；分母 $\text{DF}(w) / |\mathcal{D}|$ 代表該詞在全語料中的文件覆蓋率，量化其在全體評論中的普遍程度。取兩者之比值後再取自然對數，即得到一個衡量「該詞彙在 label 子語料中的相對集中程度」的分數：

- $\text{disc\_score}(w, l) > 0$：詞彙 $w$ 在 label 子語料中的密度高於全語料平均水準，具有 label 特異性，屬於候選 verbalizer 詞彙。
- $\text{disc\_score}(w, l) \approx 0$：詞彙分布與全語料無顯著差異，語意鑑別力低。
- $\text{disc\_score}(w, l) < 0$：詞彙在 label 子語料中的密度低於全語料平均，對該語意維度不具代表性。

### 3.x+4.3 平滑項的作用

平滑項 $\varepsilon = 0.001$ 加入於分母的 DF 項，主要作用有二：

1. **防止除以零**：對於全語料文件數極少（接近 0）的詞彙，避免計算上的數值錯誤。
2. **抑制低頻僻詞的得分膨脹**：若某詞彙僅出現在極少數全語料文件中（$\text{DF}(w) \approx 0$），未加平滑時其分數可能因分母趨近於零而異常偏高，並不代表真實的語意鑑別力；加入 $\varepsilon$ 後，此類低頻詞的得分被壓制至合理範圍。結合最低文件頻率門檻（`min_df`，預設 3），可進一步確保候選詞具備足夠的樣本基礎。

## 3.x+5 候選詞過濾機制

在完成 discriminative score 計算後，本研究依序施加四層過濾，以去除雖具高分但語意上不適合納入 verbalizer 的詞彙。

### 3.x+5.1 第一層：SQL 基礎過濾

於資料庫端聚合計算時同步套用以下基礎過濾規則：

- **最低詞頻門檻**（`min_tf`，預設 5）：詞彙在 label 子語料中的總詞頻不低於此值，確保候選詞具備基本出現次數。
- **最低文件頻率門檻**（`min_df`，預設 3）：詞彙出現在 label 子語料中的文件數不低於此值，排除僅在個別評論中出現的偶發性詞彙。
- **詞彙長度下限**（`min_token_len`，設定為 2）：僅保留字元長度 ≥ 2 的詞彙，排除單字元的助詞、標點符號等。
- **純數字排除**：排除僅由阿拉伯數字組成的 token（如「123」、「2024」），這類詞彙通常對應日期、型號等，不具語意鑑別力。
- **基礎停用詞過濾**：排除助詞、連接詞、語氣詞（如「的」、「了」、「但是」）及電商常見無語意詞彙（如「商品」、「賣家」），這些詞在各語意維度的評論中均高頻出現，不具區分性。

### 3.x+5.2 第二層：詞性白名單（POS Whitelist）

本研究採用 CKIP 中文斷詞系統對評論進行詞性標記，並依據各詞彙在 label 高信心評論中最常出現的詞性（dominant POS）進行過濾，僅保留以下詞性的詞彙：

| 詞性標記 | 定義 | 代表詞例 |
|---|---|---|
| Na | 普通名詞 | 體驗、驚喜、新奇 |
| Nb | 專有名詞 | 品牌名（由人工決定是否納入） |
| VH | 狀態動詞（形容詞用法） | 好用、神奇、厲害 |
| VE | 存在動詞 | 有 |
| VK | 心理動詞 | 喜歡、推薦 |
| VA | 不及物動詞 | 值得 |
| A | 形容詞 | 新鮮、獨特 |

副詞（D，如「超」、「很」、「真」）刻意不納入白名單，原因在於此類詞彙在正向評論中近乎普遍出現，對個別語意維度缺乏鑑別力，須保留至人工審閱環節再行判斷。

此外，本研究提供 `--exclude-nb` 參數，可進一步從白名單中移除「Nb（專有名詞）」類別，以過濾品牌名稱的干擾。中文電商評論中，被高度討論的品牌名因伴隨大量主觀評價而可能在某語意維度的子語料中頻繁出現，但品牌名本身並非語意維度的 verbalizer，需以此機制排除。

### 3.x+5.3 第三層：通用黑名單（Generic Blacklist）

通用黑名單收錄對所有語意維度均缺乏鑑別力的泛化詞彙，即「在幾乎所有 label 的高信心評論中均高頻出現」的詞彙，因此不具跨 label 的區分能力。主要包含以下幾類：

- **評論元語言詞**（meta-commentary）：「評價」、「評論」、「評分」等描述評論行為本身的詞彙，而非評論內容。
- **泛化體驗描述詞**：「效果」、「感受」、「有感」、「有效」等在各類正向評論中普遍出現的詞彙。
- **泛化認知動詞**：「覺得」、「知道」、「認為」等，此類詞彙單獨出現時無法對應特定語意維度。
- **期待類詞彙**：「希望」、「期待」、「期望」等，為泛化情感描述，不具 label 特異性。
- **人際關係詞**：「朋友」、「家人」等描述使用情境的詞彙，非語意信號本身。
- **口感 / 味道描述詞**：「味道」、「口感」、「風味」等，在保健品與食品語料中普遍高頻，但對各語意維度無鑑別力。

設計原則上，通用黑名單採保守策略：只收入「高確定性的跨 label 泛詞」，不過度排除，情感評價詞（如「超」、「好」）刻意保留至人工審閱。

### 3.x+5.4 第四層：Label-Specific 黑名單

除通用黑名單外，各語意維度設有專屬的 label-specific 黑名單，用於排除「在特定 label 子語料中意外高頻，但語意上屬語料偏誤而非語意信號」的詞彙。以 High_Novelty 為例，本研究語料包含大量保健食品評論，使得「葉黃素」、「益生菌」、「膠原」等成分名在新奇語意的高信心子語料中意外高頻出現——這是因為消費者初次嘗試保健品時常表達新奇感，但這些成分名本身並不承載「新奇」的語意，若納入 verbalizer 將造成語意混淆。

Label-specific 黑名單的設計原則與通用黑名單一致：只收入「在語意上確定不符合該維度定義」的詞彙，並保持可由研究者視語料特性擴充的彈性。

## 3.x+6 人工審閱與 Verbalizer 擴充

### 3.x+6.1 候選詞輸出格式

完成上述四層過濾後，依 discriminative score 由高至低排列，取前 $K$（預設 150）筆候選詞，寫入 `sf_keyword_candidates` 資料表。每筆候選詞記錄包含以下欄位：

- `token`：候選詞文字
- `discriminative_score`：差異化分數
- `label_total_tf`：在 label 子語料中的總詞頻
- `label_doc_freq`：在 label 子語料中的出現文件數
- `global_df`：在全語料的文件頻率
- `dominant_pos`：最常見詞性標記
- `example_comment_ids`：得分最高的前 3 筆評論 ID（供人工審閱時查閱原始評論）

其中，`example_comment_ids` 的提供尤為重要：研究者可直接查閱候選詞在實際評論中的出現脈絡，判斷其是否符合該語意維度的核心定義，而非單純依賴量化分數做決策。

### 3.x+6.2 人工審閱流程

候選詞列表並非直接整批納入 verbalizer，而是由研究者依序進行以下三種判斷：

**（一）可直接納入**  
候選詞在語意上明確對應該語意維度的核心定義，且在 example comments 中穩定以相關語意出現。此類詞彙直接納入擴充版 label descriptions。例如，「回購」在 High_Repurchase_Intent 的候選詞中出現頻繁，且查閱例句後確認均以「再次購買」之意出現，語意明確，可直接納入。

**（二）保留觀察**  
候選詞的語意具有一定程度的歧義，或在例句中並非穩定以特定語意出現。此類詞彙暫不納入本輪 verbalizer，但保留記錄，待語料進一步擴充後再行評估。例如，「發現」在 High_Novelty 的候選詞中出現，語意可能是「發現（新奇事物）」亦可能是「發現（問題）」，需要更多例句支持方能判斷。

**（三）建議排除**  
候選詞語意不符合該維度定義，或雖在語料中高頻但屬語料偏誤（corpus artifact），確認為噪聲後記入 label-specific 黑名單，避免在後續 mining run 中重複出現。

### 3.x+6.3 Verbalizer 擴充結果

經過上述人工審閱流程，本研究將 seed label descriptions 擴充為涵蓋更多中文電商語料表達形式的多關鍵詞描述。各語意維度的 seed 版本與擴充版本對照如下：

| 語意維度 | Seed（初始） | 擴充後 |
|---|---|---|
| High_Arousal | 驚豔、激動、太神了 | 驚豔、驚喜、不可思議、太神了、厲害、無敵、震撼、驚人 |
| High_Novelty | 新奇、初次體驗、相見恨晚 | 新奇、初次體驗、相見恨晚、特別、不同、難得、發現、神奇 |
| High_Repurchase_Intent | 回購意願高、忠實粉絲 | 回購、長期、固定、首選、忠實、囤貨、會再買、一直買 |
| Negative_Complaint | 憤怒、失望、反推 | 憤怒、失望、反推、客服、傻眼、過期、嚴重、可惜、問題、退貨 |
| Advertisement | 業配、廣告、湊字數 | 代言、代言人、官網、網頁、網評、風評、老牌子 |

擴充版 verbalizer 保留各維度的核心語意錨點，並增補在語料中觀察到的多樣化表達形式，使 NLI 模型在推論時能對更廣泛的中文口語表達形成語意共鳴。

## 3.x+7 方法貢獻與定位

本節所介紹之語料導向 verbalizer 擴充方法，在方法論上位於理論定義（SF 五個語意維度的核心定義）與模型輸入（NLI 的 hypothesis 端文字）之間，作為兩者之間的語料適應層（corpus adaptation layer）。其方法貢獻可歸納如下：

**一、提升語意覆蓋能力**  
透過 discriminative score 量化各候選詞在 label 子語料中的集中程度，使 verbalizer 從僅涵蓋少數研究者預設短語，擴充為基於本研究語料真實分布的多關鍵詞描述。此舉有效降低因 seed label descriptions 覆蓋不足而導致的語意遺漏問題，使 NLI 模型在中文電商評論語境中的推論信號更加穩定。

**二、保留人工可解釋性**  
與端對端的訓練式分類方法不同，本研究之 verbalizer 擴充流程需經過明確的人工審閱環節，每一筆最終納入的關鍵詞均有對應的例句佐證與審閱記錄。研究者始終保有對 verbalizer 組成的完整理解與控制能力，方法論上屬於「半自動、人工確認」的設計，避免了純統計方法可能帶入的語意噪聲。

**三、區分理論定義與實作擴充**  
本研究明確區分 SF 的理論定義（各語意維度的語意內涵，不隨語料而改變）與 verbalizer 的實作擴充（根據具體語料調整的文字化描述），確保方法的可解釋性與跨語料的可複製性。即便未來語料範圍有所調整，此流程可重新執行 sf_01 與 sf_02，在新語料中重新挖掘候選詞，並依同樣的審閱標準更新 verbalizer，維持方法的一致性。

**四、品類偏誤的主動處理**  
中文電商語料因商品品類混雜，同一語意維度的高信心子語料可能因商品類型集中而引入品類特有詞彙（corpus artifact），例如保健品語料中的成分名、物流詞彙、促銷用語等。本研究透過通用黑名單、label-specific 黑名單與 POS 白名單的多層過濾機制，主動識別並排除此類噪聲，確保 verbalizer 的語意代表性不受語料品類分布偏誤的影響。

綜上，本研究所設計之語料導向 verbalizer 擴充方法，在維持 SF 理論定義穩定的前提下，有效提升了零樣本 NLI 語意分類在中文電商評論語境中的覆蓋能力與推論穩定性，同時保留人工可解釋性，兼顧了語料適應性與方法論的嚴謹性。
