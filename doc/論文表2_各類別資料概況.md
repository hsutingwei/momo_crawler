## 一、名詞定義

| 欄位名稱 | 定義 |
|:---:|:---|
| **商品數量** | 本研究分析單位的有效樣本總數（= 爆品數 + 非爆品數）。詳見「有效樣本形成機制」節說明 |

| **非爆品（y = 0）** | 上述條件不成立之商品 |

## 二、有效樣本形成機制（論文可用說明）

### 2.1 從原始商品到有效樣本的兩階段過濾

本研究爬蟲共取得 **7,197 件**商品基本資料，但並非所有商品均能進行分類標記。有效樣本須通過以下兩個篩選條件：

```
7,197 件商品（products 表）
   │
   │ ① 剔除無評論商品（共 2,256 件）
   │   → 無法建立評論特徵，不納入研究
   ↓
4,941 件有評論商品
   │
   │ ② 剔除評論批次無法對應銷售快照商品（共 2 件）
   │   → 無法計算銷售標籤，不納入研究
   ↓
4,939 件有效樣本（版本 A）
   │
   │ ③ 套用 v2_error_prod 品質過濾（共排除 1,210 件）
   ↓
3,729 件有效樣本（版本 B，論文正文使用）
```

### 2.2 條件一：商品必須具有評論資料

**剔除數量：2,256 件（佔 7,197 的 31.3%）**

評論資料是本研究特徵工程的核心來源（評論動能、語意分數、TF-IDF 等）。無任何評論的商品無法建立任何輸入特徵，予以排除。

### 2.3 條件二：銷售快照須能與評論批次對齊

**剔除數量：2 件**

本研究的標籤計算邏輯需要將「銷售快照」與「評論爬取批次」進行時間對齊（Temporal Alignment）。具體而言，每次爬蟲抓取評論時記錄一個批次時間（`capture_time`），對應的銷售快照須在該批次時間**之前或同時**存在，才能取得「當時的銷售量」。無法進行此對齊的商品（如：已下架、未具銷售快照）予以排除。

### 2.4 爆品標籤計算邏輯（next_batch 模式）

進入有效樣本集後，每件商品依下列流程計算二元標籤 y：

**Step 1**：依商品彙整各爬蟲批次（`capture_time`）的最新銷售量 → 形成時間序列

**Step 2**：以 `LAG()` 函數計算相鄰批次的前期銷售量（`prev_sales`）

**Step 3**：對截止日 T 後的每個批次，判斷是否滿足：

```
batch_time > T = 2025-06-25
AND prev_sales IS NOT NULL        ← 存在前一期可比較
AND (sales_count − prev_sales) ≥ 10   ← absolute 策略，Δ ≥ 10
```

**Step 4**：若**任一**批次滿足上述條件 → 標記為爆品（y = 1），否則為非爆品（y = 0）

### 2.5 各批次數分佈

爬蟲共進行 **2～9 次**不同時間點的捕獲（部分商品只被爬取一次）：

| 批次數 | 商品數 |
|:---:|:---:|
| 1 | 1,929 |
| 2 | 1,055 |
| 3 |   749 |
| 4 |   704 |
| 5 |   357 |
| 6～9 |   145 |
| **合計** | **4,939** |

> [!NOTE]
> 僅有 1 個批次的商品（1,929 件）無法計算前後期銷售差 Δ（因 `prev_sales = NULL`）；此類商品一律標記為 y = 0（非爆品），仍納入訓練集以保留資料規模。
>
> 在 4,939 件有效樣本中，真正具有「截止日後 AND 有前期對比」能力的商品共 **2,899 件**；其餘 2,040 件因僅有截止前資料或只有單一批次，標籤 y = 0 是基於「未觀察到爆品行為」的保守假設。

### 2.6 v2_error_prod 品質過濾（版本 B）

**v2_error_prod** 是一套以模型集成誤差（Ensemble Error）為依據的商品品質過濾機制，旨在移除高雜訊或高異質性樣本，使訓練集更具一致性：

- 以 4 種特徵組合（Base / Price / Kin / Nov）分別訓練 XGBoost（10-Fold Cross-Validation）
- 凡在 **≥ 3/4 個模型中均預測錯誤**的商品，視為標籤行為難以學習的異常樣本
- 共排除 **1,210 件**（佔版本 A 有效樣本 4,939 的 24.5%）

此過濾的目的是提升模型訓練訊號的品質，非作為資料集代表性的篩選依據：
- 由於排除了 1,210 件商品，專屬於這些商品的評論也連帶不進入模型訓練，因此總訓練評論數由 132,640 筆降至 87,849 筆（減少約 33.8%）。
- 爆品正類比例從 9.4%（版本 A）輕微降至 9.1%（版本 B）。
